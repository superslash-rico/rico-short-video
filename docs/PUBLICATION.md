# 公开发布边界

本仓库是制作方法、可复用脚本、公开目录与适用经验的分发版本。维护者自己的全局Skill可以包含本机配置和经授权的内部参考，发布版通过明确文件范围和结构化字段筛选生成。

允许公开的内容包括：三模式流程、人物/屏幕编排规则、交接模板、通用Rico表达方法、辅助脚本、官方公开链接、去账号后的历史字段观察。

发行包不包含：个人.motion包、Key/Cookie/Token、账户授权或验签回执、内部飞书课程目录、用户文件清单和私人素材、真实成片与原片、第三方预览字节、原项目Git历史。

首次版本从全新的Git目录建立，仅提交检查后的公开文件。后续同步来源Skill时应比对公开文件、保留本仓库适配，并重新执行结构、引用、测试和敏感信息检查；任何新文件都先按公开范围判断。自动检查不是不存在敏感内容的绝对证明，需要同时人工审阅实际差异。

对外推送、Release和向他人发送内容仍以用户当前的明确要求为依据。本仓库的使用者可保留本机改进建议，维护者审核后再并入正式版。在制项目记录使用版本，避免更新一半改变制作依据。

没有将公开可访问等同于第三方可再分发许可，未给本仓库自动选择MIT等开源许可证。
