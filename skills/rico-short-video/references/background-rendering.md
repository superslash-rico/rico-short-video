# 点阵、微光与 SVG 资源的导出验收

用于专业 MG 背景及复用 SVG pattern、gradient、mask、clipPath 的场景。普通实拍上的透明提示不强制添加背景；已发布视频的排查不自动授权修改成片。

## 已复现的问题与边界

一次三个独立 MG 连续导出中，固定同名 `shared-mg-background-dots` 使第一段有点阵，后两段缺失。相同尺寸、颜色、透明度下，仅改成每段唯一 ID 后三段都正常；显式绘制圆点也正常。当前证据定位到该宿主的跨 MG 资源引用/复用触发条件，未定位其内部缓存函数，不推广为所有 SVG pattern 都不可用。纯图形回归记录见[验证范围](data/background-rendering-case.json)，不附私人视频、账号或工程 ID。

## 新制作的实现要求

- 共享组件 0.2.1 默认直接绘制圆点，移除了点阵对 `url(#pattern)` 的依赖；圆点保持原尺寸、颜色、透明度及弱视差。网格按实际相机覆盖画布，不另加固定裁切窗。
- 微光等仍有引用的资源必须使用稳定的每实例 `resourceKey`。暴露 `resourceKey` 文字属性，导入时给每资产独立的预览默认键；放置后用主工程返回的项目/场景/实例身份生成唯一值，写入每实例覆盖并回读，同一实例多背景层再追加层名。当前宿主的导入校验未提供可依赖的 `item.id`，不能假定组件能自动取得实例ID。资源键使用ASCII字母、数字、点或连字符，可由主工程实际ID组合生成，不能直接使用带空格的标题。缺失时组件报错，不能退回固定公共名称。
- 同步核对资源定义和每处引用；同资产的两个实例也不能共用同一键。不用 `Math.random()`、时间戳或随帧变化的 ID，随机/倒序寻帧应复现相同画面。ID 在同一节点树内应唯一，宿主隔离行为仍以实测为准。[SVG 规范](https://www.w3.org/TR/SVG2/struct.html#IDAttribute)。
- `patternId` 仅作为旧代码的显式参数别名保留，已无公共默认值；新入口统一用 `resourceKey`。旧工程使用自己的锁定副本，不因技能更新自动替换成片。

## 组件复用和交付检查

建立新宿主兼容性基线或修改背景组件时，把多个独立 MG 连续导出，并覆盖同资产重复实例与乱序寻帧；检查每段实际编码。沿用同一已验证组件时，不为每条重建测试工程，但每条实际成片仍逐段验收。

逐个动画段选实际可见的稳定帧及有风险的进出/运动中途，在无人像、纸面、字幕遮挡的背景区检查点阵和微光。全幅检查层级，再以原尺寸及约360—390像素宽看可见性。全屏真人完全遮挡背景的瞬间可注明不适用，不能拿遮挡区的空白当纹理缺失，也不能把不可观测写成通过。

交付记录保存本次 MP4 的 SHA、场景/帧号、背景区域、点阵与微光各自结论及截图。源码存在、首段正常、编辑器预览、色彩门禁或全片解码都不能代替这项检查。缺失则修对应模块并重验相邻段；未通过不标记包装验收通过，也不因此重复索要用户已经给出的制作授权。

## 像素辅助检查

在已经人工确认无遮挡的区域使用 [check_dots.py](../scripts/check_dots.py)。配置为样本列表，每项含 `frame`、可选 `fps`、`roi:[left,top,right,bottom]`、`roi_reviewed_unobstructed:true`、`scene_key`，以及按本条基准设定的对比阈值和最少亮点像素数。

```text
python3 scripts/check_dots.py --video <实际成片.mp4> --samples <本条样本.json> --report <本条检查结果.json>
```

默认交付模式要求所有样本有点阵；`--regression` 才允许对已知缺失的负例设置 `expected_present:false`。回归匹配不能写成交付通过。需已有 FFmpeg、ffprobe、Pillow；缺依赖或区域未审看时停止检查并记录未验证，不为此安装转写模型。

脚本输出局部细亮点的数量与异常结果，不能判断整体美感、微光质量或替代手机观看。阈值取自当前画幅/点径/编码的实际基准，不能把本例阈值固化为所有视频标准；文字或纸面进入 ROI 后重新选区。
