# 整体先行、模块精修、镜头与对象编排

用于[原生MG创作](animation-production.md)中的设计与验收。先读[共享视觉与质量规范](mg-visual-standard.md)，将同一工艺适配为竖屏全画幅构图与手机观看节奏；不改变[presenter-layout.md](presenter-layout.md)的人像显示逻辑。

## 整体先行

理解整条讲述后，按观众的理解任务划分场景。一幅整体应让人看出“这是什么、有哪些主要部分、当前重点在哪”。较长论证可分成几个各自完整的阶段，用对象身份、方向和过渡连接；开场与结果的整体可以不同，重排过程要可追踪。

先做开场整体和结果整体设计帧，重要中间重组另做一帧。先以平面设计组织分组、主次、比例、对齐、间距、留白和视觉重心，再设计纵深与摄影机。距离有语义，相近用途的对象形成联系；避免中心空洞、角落堆挤、孤立小片、同等强度卡片和意外切边。不能把若干独立近景散到远处，再无限拉远当总览。

同一场景的透视、光向、材质、阴影和遮挡一致，层级服务内容。专业场景沿用共享深紫黑点阵/横向微光与同源材质规范；普通原片上的局部透明叠加按实际需要保留原底。

竖屏使用完整输出画布和可超出画面的世界空间；人物、字幕和平台区域作为动态排版约束，不能据此建立固定小窗口或clip。整体构图包含与人物的平衡。先看正常播放尺寸，再用同比缩小的竖屏缩略图看轮廓、分组和重心；正文阅读另用约360—390像素宽手机尺寸检查。无需把横屏320×180检查尺寸迁进来，也不按固定面积比排版。若整体仍难理解，先重排、归组、调整层级或拆阶段，再开始特写和运镜。

## 模块要经得起特写

模块先有完整的阅读单位：真实文字、图像、状态、数据及限定条件。标题、正文、批注和证据各有读序；长内容按语义换行或分阶段揭示。相近用途的字号层级、边距、边界与材质协调，但不把全部内容强制做成卡片。

为关键对象明确身份与前态、可见过程、后态。比如“目标不清 → 逐项补充验收条件 → 按条件检查结果”，需要看见条件如何进入目标、又如何用于检查；只轮流出现三个名词没有解释机制。全景到特写再回整体仍是同一对象，结果重排要演出来。

记录最长文字、最多同时在场对象、最大缩放/旋转、翻面临界角、交叠、人物经过和退出等危险状态。检查缩放原点、对象裁切、绘制顺序、正反面和实际投影；坐标/z值合理不能代替实际合成。不得用空白页、假细字、装饰编号或无关纹理代替信息。

## 镜头与图形分别设计

摄影机负责“带观众观察哪里以及为什么”，对象自身运动负责“什么发生了变化”。两者各有起点、路径、落点、时机和缓动，不把所有图层一起移动当作知识动画。

| 观察方式 | 表达用途 | 必须解决 |
| --- | --- | --- |
| 推近/特写 | 进入依据、操作或细节 | 完整主要阅读单位、足够抵达后的读时、与原对象对应 |
| 拉远/整体 | 揭示组成、对比或结果 | 抵达已设计的整体，主要部分仍可辨，不成为散点 |
| 横移/跟随 | 观察相关部分或同一材料的处理 | 身份与方向连续，不穿越大段无意义空白 |
| 升降/视角变化/小角度环绕 | 揭示层次、覆盖与厚度 | 提供新信息、文字有可读角度、比例和遮挡可信 |
| 遮挡揭示/焦点转移 | 顺序交代依据与新重点 | 遮挡关系明确，关键文字不因模糊或翻转失读 |
| 甩镜/强节奏转换 | 有联系的话题转折 | 前后关系明确、落点迅速清楚、避免连续堆用 |
| 稳定停留/轻微读时推进 | 读懂当前依据或结论 | 不边大幅漂移边让观众读长句 |

这是工具箱，不要求每段用齐。横竖屏共同验收整体—细节反差、抵达速度与读时，倍率按主要阅读单位与当前画幅重新计算，不锁死4倍或照抄旧机位。以认可样段检查推拉的量感：整体与细节应有清楚的投影尺寸反差，不能用几乎不可察觉的微缩放代替需要的推近拉远；抵达后的阅读轻推与场景转场分开设计。过渡可以短，抵达后要可读；具体秒数、幅度与轻推按口播和内容判断，不套固定帧数。2D缩放、2.5D视差和真实3D分别记录实际机制，不把平面旋转称为真实环绕或景深。

同一对象保持到镜头实际离开，下一主体在镜头抵达时已经就绪。相机换焦点与对象退场不要造成一帧空场；返回结果整体时保留身份与空间方向。图形摄影机不接管人像窗口、原生字幕或同源背景的时钟与调度。

## 时间与声音一起排

从实际口播/操作锚点倒推动作发生、抵达、阅读和离开。先满足理解，再用有意义的音效加强提取、修改、落座或合并；按当前素材有效瞬态对齐，不按文件起点对齐。人声清楚、设备证据声保留、音乐由主工程处理；具体音量不跨片硬套。

分镜由助手记录在同一份[交接清单](../templates/animation-handoff.json)：理解目标、内容依据、对象状态、整体/细节设计、镜头路径与实际实现、对象动作、读时、人物/字幕/真实资料的保护区、音效事件、危险状态与检查范围。不要求用户填写设计参数；只在用户要求先看方案/选样时停在该节点。

## 设计与运动验收

- 每个开场/中间/结果整体看分组、轮廓、重心、主次和留白；每个主要阅读状态看完整含义、字形/换行、数据、边缘、光影和真实素材。
- 在实际主工程组合中看进入、抵达、稳定阅读、最大重叠/缩放/旋转、翻面、主体交接、返回整体和退出；危险处看相邻帧，排查反字、意外裁切、穿透、抖动、跳位、突变和空场。
- 把人物运动全程与字幕、操作目标一起检查，不能只看MG单独预览或静止终点。屏幕保护区随真实操作变化，不靠动画盖掉难看的原片。
- 随机跳转、倒序取帧与从前面播放抵达时比较相同时间状态；检查字体/媒体加载和实际保存参数，临时测试覆盖恢复后回读。
- 用当前导出连续检查节奏、观看方向、阅读、运动强度和声画事件，跨整条查看重复与疲劳。完整解码、抽帧、连续观看、主观听审、用户审美/节奏和观众理解各记实际范围与状态。

发现问题只修受影响模块与相邻交接，更新源/实例/预览的版本对应并重检；技术通过不写成用户认可，未做的检查保留未验证。
