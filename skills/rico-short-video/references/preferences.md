# 已确认的制作偏好

这些偏好来自Rico视频制作流程。为Rico制作时沿用；其他讲述者优先采用其明确要求与本机profile.json，不移植Rico的身份、经历或权益。个人账号授权不得由本公开版继承。

- 面向零基础到初级学习者，以实用 AI 技能建立 Rico 的个人 IP。
- 公开作者署名统一为“Rico”。片头、片尾、名牌、封面、发布文案与作者元数据不添加“其他私人姓名”。这是用户对今后所有视频的明确要求。
- Rico项目曾确认的会员权益方向为系统化AI课程、直播与问答；每条任务仍核对当前讲述者已提供且已确认的真实权益。课程目录不证明具体课节已上线；公开介绍具体课名与权益前核对。
- 单条口播尽量在两分钟以内。写稿复用 rico-spoken-script；正文可直接复制到提词器。
- 按原片和任务入口选择流程：未拍的露脸口播可先写稿定稿；拍屏讲解可先给简短演示提纲；已拍好并要求制作时直接据原片分析、转写和剪辑，不倒补写稿审批。原片由用户录制，题材与重点沿用用户已确定的内容。
- 保留原片与定稿。剪掉无意义停顿、重复、口误和不必要的语气词，保留必要的思考、强调、转折与事实限定。
- 露脸口播及混合模式有同步可用露脸主轨的区间，真实动态人物持续可见，不使用人物完全消失的纯动画段。具体适用范围先按source-modes.md记录；纯拍屏和无相应露脸素材的屏幕段以真实操作和本人原声为主，不循环或冻结短露脸素材补人物。采用真人全画幅加透明动画，或资料主画面加圆形/圆角矩形人物窗；人物窗位置与大小保护脸部、字幕和资料关键内容。缩放、位移平滑衔接，保持同一口播时钟，不以静态头像或冻结帧代替。
- 露脸口播，以及混合模式有可用且匹配内容的真实露脸开场时，开头2—3秒先以全画幅清晰真人建立信任与个人IP，默认前3秒。纯拍屏采用真实结果/核心价值开场，不强制补拍露脸。用户已明确认可本条V2的开头做法。标题和字幕可放在实拍留白处，不能遮脸或用纯动画/Logo片头取代这段真人开场。
- 人物/资料缩窗及原本整帧纯色背景，采用“同一时点的相应源视频铺满画布＋纯色半透明罩”：露脸段用真人视频，纯拍屏段用屏幕视频。清晰主展示区和字幕放在罩层上方；拍屏不补造人物。背景人像只需隐约可见少量轮廓与动态，不清楚显出另一张抢眼的大脸；清晰人物窗、资料与字幕叠在上方。颜色和透明度按内容可读性调整，保留少量真实纹理，不能完全盖成不透明纯色；不固定墨绿或某个透明度为系列标准。所有复用画面保持同一口播时钟，只保留一份主原声。
- 用户明确要求人物呈现根据内容动态变化，位置和形态应能变化；不将整条固定在同一角落、同一尺寸或同一窗形。具体调度按presenter-layout.md选择，重要阅读段保持必要稳定；具体样式仍以真实样段与用户反馈为准。
- 使用 MotionGit 包装，动画密度高、内容丰富且专业，动画配合音效。用户已明确要求完整V2由ChatCut主剪辑、MotionGit做动画；按此分工执行，具体审美与效率结论仍以真实成片和用户反馈为准。
- 用户要求有考虑全面的MotionGit模板选取策略，以最终视频质量和效果为目标。具体比较、样段与经验复用按motiongit-selection.md执行，不把首条试跑模板当作已认可的系列标准。
- 在使用者实际授权范围内收集官方可领取模板，并按任务检查更新及复用本机缓存；不得继承维护者的账号或素材传云授权。实际个人包与技能分开，具体库索引、增量获取和版本锁定按motiongit-library.md执行；领取失败和未开放项单独记录，不扩大到付费或账号权限变更。
- 拍屏讲解与混合模式按source-modes.md和screen-explainer.md执行。剪辑同时参考原声与点击/输入、反馈、等待、结果和解释的真实先后关系；无口播长等待可压缩或加速并标注，不删掉必要步骤。手机＋同步录屏是可选提质方式，纯手机原片也可开始；只留一份主讲解，双源以真实事件核对同步。
- 拍屏动画按语义多次出现，优先用关键词、编号、线条、当前状态和流程节点透明叠在真实视频上，避免大面积纯色卡遮挡；关键按钮、反馈、结果和原生字幕始终受保护，具体次数和位置按本条素材选择。
- 放大和高亮必须准确展示当时口播所指的真实内容。手持拍屏随画面变化重新定位目标；补录/截图要核对页面状态与实际结果，不能生成文字冒充不清楚的原界面。长句或多行文字优先使用框选与矩形局部放大卡；圆形放大镜仅用于适合完整容纳的短内容，不能截半句、放空白或与当前语句错位。
- 视频讲解中尽量避免字多、字小、手机上看不清的整页资料卡，不能以“素材真实”代替可读性。主要信息用大字短句呈现，真实资料按当前口播裁切放大，长内容拆开逐项展示；必要的整页概览只作背景交代，并配合清楚的目标局部。以最终人物、动画与字幕组合在手机观看尺寸下能读懂为准，不能依赖观众暂停或放大。这条阅读要求不直接套用到封面素材。
- 优先官方界面、原始公告、真实录屏、用户提供的实拍与文件。图解和生成图片可辅助表达，不能伪装成真实产品界面或实测结果。
- 封面主题文字鲜明，画面与主题及真实素材相关。工具目录等真实资料可在封面上表现内容丰富，不要求素材小字逐字可读；保持主标题、人物和相关素材的层次，不因小字难读自动删除。先读取当前讲述者已认可的封面作为样式依据。
- 默认交付16:9、3:4、4:3三比例并分别构图，不只裁切一张。为Rico制作时沿用已认可的深色冷暖背景、米白大字、黄绿重点、橙色笔刷和左上作者标识；其他讲述者优先采用其本人风格与明确要求。
- 视频无露脸时，封面仍可按需要使用已获当前使用者用途许可的本人肖像；不把视频人物规则套成封面禁用人像，也不要求每张封面必须露脸。可在许可内自然淡化临时瑕疵、均匀肤色和提亮牙齿，保留五官、年龄、眼镜与辨识度；具体程度由本人审核，不自动扩展到视频人物处理。
- 视频号可明确介绍会员；抖音、小红书、B站先引导关注与继续学习。四个平台分别写标题、文案、标签和适用片尾。
- 使用 Chrome 准备四个平台的发布，用户协助登录。所有平台最终发布按钮由用户自己点，或在用户明确授权助手点击后再点；“投稿”“确认发布”“定时发布”等造成最终提交的按钮同样适用。内容通过审核、允许上传或验证草稿不等于允许最终提交。
- 平台登录由用户接手：先打开浏览器网址，再退出浏览器控制，等用户明确说已完成登录后才恢复控制并核对账号。用户登录期间不轮询、刷新或操作该登录页；中途登录失效也按同样方式交接。本轮已明确完成登录的平台直接接续，不要求重复登录。
- 额外收费素材与外部 API 默认预算为 0 元。发生新费用前提供具体报价并取得相应授权。
- 每次制作完成都复盘，按evolution.md形成通用改进建议；公开安装版不自动修改上游或提交私人内容。
- 用户明确说本条任务完成后，自动整理该视频目录供长期存档：先将有价值的制作方法沉淀进技能，再删除无用中间产物与淘汰版本；保留最终成果、唯一原片和继续修改必需的工程依赖，按archiving.md执行。只处理这条视频目录，不删除共享模板库、浏览器数据或云端草稿，不由“制作完成”推断发布授权。

技术默认：用户未指定时，可先按竖屏 9:16、1080×1920、30fps 制作待审版本；以原片、模板实际能力和当前平台要求核验，记录选择依据。这些参数是实施默认值，不是用户已经验收的视觉标准。

制作方法：用户已要求并实跑ChatCut主工程、MotionGit重点动画的分工，详见hybrid-workflow.md。首条V4制作任务于2026年10月17日被用户明确宣布完成；它可作已完成路径参考，不能据此推导所有模板、交接格式、配色或封面方向均已认可。用户的后续具体指令优先。
